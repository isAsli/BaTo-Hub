# Support

For help, contact @DatPHP.

## What to include in a bug report

Include:
- BaToHub version
- Operating system
- Panel in use
- Steps to reproduce
- Log output
- Expected and actual behavior

## Supported

Supported:
- Ubuntu 22.04 and 24.04 on amd64 and arm64
- Rebecca panel integration in this release
- Backup, restore, import, and update flows in this release

## Not supported

Not supported:
- Arbitrary server modifications
- Panels or configurations not shipped with BaToHub
- Issues caused by manual edits outside BaToHub-managed files

## Response expectations

Reports are reviewed when possible. Include enough detail to allow reproduction.
