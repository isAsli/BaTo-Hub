# Security

BaToHub takes security seriously. This document describes how to report vulnerabilities and what is in scope.

## Contact

For vulnerability reports, contact @DatPHP.

## Scope

In scope:
- BaToHub shell source code
- Panel integrations shipped with BaToHub
- Configuration and state handling
- Backup, restore, import, and update flows
- Template and SSL management code

Out of scope:
- Third-party panels themselves unless a vulnerability is in the BaToHub integration code
- Issues that require physical access to the server and no Bailey software compromise
- Issues that require credentials the user did not configure

## Supported versions

Only the latest release is supported for security fixes.

## Response timeline

We aim to acknowledge reports quickly and work with reporters to address valid issues.

## No bug bounty

There is no bug bounty program at this time.

## Disclosure

Please report vulnerabilities privately. Do not publish exploit details before a fix is coordinated.
